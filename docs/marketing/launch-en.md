# Arshy v0.1.0-alpha.1 public preview

Arshy gives AI agents a standard MCP command layer that turns noisy terminal
output into traceable diagnostics with status, exit codes, locations, codes,
deduplication, and optional source context.

The preview supports macOS and Linux and is looking for real tasks, especially
build and test failures. Try one task and tell us whether setup worked, whether
the diagnostic was visible, and whether the Agent needed extra queries or
repeated execution.

Arshy runs locally and does not upload telemetry. It does not claim a fixed
token-saving percentage; the project is measuring complete-task outcomes.

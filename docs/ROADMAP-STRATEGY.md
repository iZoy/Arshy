# Roadmap

## v0.1.0-alpha.1: validate real use

- reliable standard MCP results for text and structured clients;
- bounded, recoverable command output with explicit execution state;
- reproducible installation and Agent onboarding on macOS and Linux;
- local, voluntary diagnostics and GitHub-based feedback;
- honest complete-task efficiency measurement without a fixed saving claim.

## First 30 days

Operational targets are 10 confirmed external setups, five real projects with
task feedback, and three users who confirm reuse at least one week later.
These goals measure learning and do not delay the preview.

Priorities:

1. P0: duplicate execution, uncontrolled processes, or serious data problems.
2. P1: installation, standard MCP connection, or missing diagnostics.
3. P2: formatting, convenience, and new parsers ranked by observed use.

The first efficiency iteration separates response and storage budgets, then
compares native shell, the preview, and the changed response policy on complete
tasks. Success rate is evaluated before token count, calls, retries, and time.

## v0.1.0

The stable release requires a stable MCP result contract, no unresolved P0/P1
issues, evidence of external repeated use, and documented material limitations.

## Non-goals

Client-specific adapters, shell hooks, automatic telemetry uploads, OS/container
sandboxing, native Windows support, crates.io, and Homebrew are outside the
public-preview scope.

# ADR-0005: 拒绝旧版与未知 MCP 工具

- **状态**: 部分被 ADR-0007 取代（2026-08-24）；移除 legacy 与未知工具 fail-closed 仍有效
- **相关代码**:`src/proxy/handlers.rs`、`src/main.rs`、`docs/reference/cli.md`

## 背景

MCP 接口应保持精简且职责明确。未知工具名应返回清楚的错误，而不应被当作命令执行。

## 决策

- 只公开三个职责明确的工具：`arshy_exec`、`arshy_query` 和 `arshy_task`；
- 未知工具名返回 `METHOD_NOT_FOUND`；
- 使用客户端无关的 `arshy mcp config` 命令完成接入，不维护各客户端专用的集成命令。

## 理由

1. 明确的工具接口更容易被客户端与贡献者正确使用；
2. 把未知工具当作执行输入是不安全的回退行为；
3. 客户端无关的设置流程不需要为每种客户端维护单独的运行时适配器。

## 后果

- 正面：MCP 表面更干净、危险默认消除、CLI 表面收敛；
- 负面：未来若需兼容旧客户端需重新引入（记录为已知成本）；
- 风险：仍使用旧工具名的客户端需要更新配置。
